# Logs

Query, search, export, and monitor RouterOS logs.

| Tool | Description |
|------|-------------|
| `get_logs` | Fetch log entries with filters |
| `get_logs_by_severity` | Filter by severity level |
| `get_logs_by_topic` | Filter by topic |
| `search_logs` | Search log message text |
| `get_system_events` | System events (login, reboot, etc.) |
| `get_security_logs` | Security-related entries |
| `clear_logs` | Clear the log buffer |
| `get_log_statistics` | Log buffer statistics |
| `export_logs` | Export logs to a file on the device |
| `monitor_logs` | Poll logs over a duration (max 60s) |
