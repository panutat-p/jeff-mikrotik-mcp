# Packages

Manage RouterOS packages: list, enable, disable, uninstall, and apply pending changes.

| Tool | Description |
|------|-------------|
| `list_packages` | List installed packages |
| `get_package` | Get package details by name |
| `enable_package` | Enable a disabled package |
| `disable_package` | Disable a package |
| `uninstall_package` | Remove a package |
| `apply_package_changes` | Apply pending package changes (reboots router) |
