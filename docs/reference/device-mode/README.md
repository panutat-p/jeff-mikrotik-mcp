# Device Mode

Query and update RouterOS device-mode settings. Container and advanced features may require physical reset confirmation.

| Tool | Description |
|------|-------------|
| `get_device_mode` | Print current device mode |
| `list_device_mode_settings` | Print device mode configuration |
| `update_device_mode` | Update device mode flags (5 min timeout) |
| `cancel_device_mode_update` | Cancel pending device mode update |
