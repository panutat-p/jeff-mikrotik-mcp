# Backup and Export

Create backups, exports, and transfer files via SFTP.

| Tool | Description |
|------|-------------|
| `create_backup` | Save a `.backup` file on the device |
| `list_backups` | List backup and export files |
| `create_export` | Export full configuration |
| `export_section` | Export a specific RouterOS section |
| `download_file` | Download a file via SFTP (base64) |
| `upload_file` | Upload a file via SFTP (base64) |
| `restore_backup` | Restore from backup (reboots) |
| `import_configuration` | Run an `.rsc` script on the device |
| `remove_file` | Delete a file from the device |
| `backup_info` | Get metadata for a backup file |
