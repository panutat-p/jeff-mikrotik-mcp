# Email and SMS

Configure and use RouterOS email and SMS tools.

| Tool | Description |
|------|-------------|
| `get_email_settings` / `set_email_settings` | SMTP configuration |
| `send_test_email` | Send a test message |
| `get_sms_settings` / `set_sms_settings` | SMS gateway configuration |
| `send_sms` | Send an SMS |
